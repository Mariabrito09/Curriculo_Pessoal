## 🎯 Objetivos do Projeto

- Aplicar **HTML5 Semântico** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Criar navegação rápida entre seções utilizando links ancorados (`#sobre`, `#projetos`, `#contato`).
- Organizar dados em **tabelas estruturadas** com cabeçalho (`<thead>`) e corpo (`<tbody>`).
- Construir **formulários funcionais** utilizando elementos acessíveis (`<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>`, `<textarea>`).
- Desenvolver a estrutura base para a exibição de projetos acadêmicos e formas de contato profissional.

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **HTML5:** Estruturação semântica da página.
- **Formulários Web:** Entradas de dados com tipos específicos (`text`, `email`, `select`, `textarea`).
- **Atributos de Acessibilidade:** Uso de `alt` em imagens e associação de `label` com `id`.

*(Futuras atualizações contarão com estilização via CSS3 e integração com PHP e MySQL)*
